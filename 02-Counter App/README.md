# 🔢 Counter App

A simple and modern Counter App built with React.  
This project allows users to increase, decrease, reset, and automatically increment the counter.

## 🚀 Live Demo

[View Live App](YOUR_VERCEL_URL)

## ✨ Features

- ➕ Increase counter
- ➖ Decrease counter
- 🔄 Reset counter to `0`
- 🤖 Start Auto counter
- 🎨 Modern glassmorphism UI
- 📱 Responsive design
- ⚡ Built with React

## 🛠️ Technologies Used

- React
- JavaScript
- CSS
- React Icons
- Vite
